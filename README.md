# Persian ABSA Project

## Project Overview
Persian Sentiment Analysis and Aspect-Based Sentiment Analysis using ParsBERT.

## Domains
- Food and Beverages
- Cosmetics and Personal Care

## Method
- Persian text preprocessing
- ParsBERT
- Sentiment classification
- Aspect-Based Sentiment Analysis

## Files
- persian_absa_analysis.py: Main project code
- Persian_ABSA_Project_Results.ipynb: Notebook with project results

## Limitations
The cosmetics and personal care domain currently uses a shared model due to the lack of an independent cosmetics training dataset.
