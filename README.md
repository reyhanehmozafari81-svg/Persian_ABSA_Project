# Persian ABSA Project

## Project Overview

This project focuses on Persian Sentiment Analysis and
Aspect-Based Sentiment Analysis (ABSA) using ParsBERT.

The system analyzes Persian user reviews and identifies
sentiment polarity and relevant aspects.

## Project Objectives

- Analyze sentiment in Persian texts.
- Identify sentiment related to specific aspects.
- Apply Transformer-based language models to Persian NLP.
- Develop an interactive interface for entering Persian reviews.
- Provide sentiment analysis for food, beverages,
  and cosmetics and personal care domains.

## Domains

- Food and Beverages
- Cosmetics and Personal Care

## Methodology

1. Data preprocessing
2. Persian text tokenization
3. ParsBERT-based model preparation
4. Sentiment classification
5. Aspect-Based Sentiment Analysis
6. Model evaluation
7. Interactive result visualization

## Limitations

The available cosmetics and personal care dataset
and independently trained model may be limited.
Therefore, results for this domain should be interpreted
according to the available data and training configuration.
